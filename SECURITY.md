# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it privately using [GitHub's built-in reporting tool](https://github.com/CommandLineCoding/lipi/security/advisories). Please do not open a public issue. We appreciate responsible disclosure and will acknowledge your report as soon as possible.

## Scope

Reports are especially welcome for:

- The native core (`core/`): memory-safety problems when decoding or processing untrusted images and PDFs
- The model and language-pack download and verification path (checksums, file handling)
- Anything that would break the privacy promise, such as the app gaining a network permission or sending data off the device
- Local data protection in the app (stored documents, the app lock)

Thank you for helping to keep Lipi secure!
